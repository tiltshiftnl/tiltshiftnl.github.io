  Maandag 16 november, 14:00 tot 15:00, online: Werken aan Publieke Code.

  Dat is het maandelijkse inloopspreekuur over de Standaard voor Publieke Code. De Standaard is een set criteria die publieke organisaties helpt om samen software en het bijbehorende beleid te ontwikkelen en te onderhouden.

  In het spreekuur kijken we samen naar de criteria, naar wat er nog mist, en hoe we de Standaard in ons werk gebruiken. Iedereen die met publieke code werkt, kan aanschuiven.

  Tiltshift organiseert de meetups samen met ICATT. Aanmelden gaat via Opensourcewerken. Op standaardvoorpubliekecode.nl staan de Standaard zelf en de mailinglijst voor de volgende meetups.

  Aan de slag.
