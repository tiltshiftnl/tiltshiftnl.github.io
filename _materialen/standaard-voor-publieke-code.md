De Standard for Public Code is gemaakt door de Foundation for Public Code. Op [standaardvoorpubliekecode.nl](https://standaardvoorpubliekecode.nl/) staan de Nederlandse vertaling, de Engelse versie en een presentatie van de criteria.

## Gedrukte exemplaren

Gedrukte exemplaren van de Nederlandse vertaling kun je bestellen voor 30 euro per stuk (excl. btw, inclusief verzendkosten). Neem daarvoor contact op met [Johan Groenen](/mensen/johan-groenen/).

## Met Tiltshift

Wij gebruiken de Standaard in drie workshops, op drie momenten in een opdracht: de [Publieke Code Kick-off]({% include workshop-url.html naam="publieke-code-kick-off" %}) bij de start, de [Publieke Code Check-up]({% include workshop-url.html naam="publieke-code-check-up" %}) tussentijds en de [Publieke Code Review]({% include workshop-url.html naam="publieke-code-review" %}) bij oplevering of overdracht.
